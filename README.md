# TID exercises — Leonie

Solo exercises for **Technical Interaction Design**, ITU Copenhagen, Autumn 2026.
One folder per week, each a standalone Vite + React app.

| week | topic | what I built |
|---|---|---|
| [week-01](week-01) | Components, props, state, lists & keys | A to-do list rendered from an array with `.map()`, a `TodoItem` component taking a `text` prop, keyed by the item text. |
| [week-02](week-02) | Forms, todo state & local storage | A to-do app with controlled input, object-based items, add, toggle and delete actions, an empty state, and persistence with `useEffect` and local storage. |

## Running any week

```bash
cd week-XX
npm install
npm run dev
```
